            System Architecture & Dual Backends
          

          
Comparison between the Web (batchexecute) and Android Mobile gRPC transports.

        

      


      

        
Web Transport vs. Android Mobile Backend


        

          
            

              Dimension
              Web Backend (Default)
              Android Backend (Opt-In)
            

          
          
            

              Protocol
              Google batchexecute RPC over HTTP/2
              Mobile gRPC Service over HTTP/2
            

            

              Authentication
              Browser Cookie Session (Playwright or Chrome)
              OAuth Master Token (master_token.json) & short-lived bearer tokens
            

            

              Headless Server Resiliency
              Requires periodic cookie refresh
              Self-heals automatically without browser dependency
            

            

              Transport Speed
              Standard web RPC overhead (~350ms)
              Compact binary gRPC payloads (~140ms)
            

            

              CLI Selection
              Default: notebooklm
              notebooklm --backend android
            

            

              Python Client
              NotebookLMClient.from_storage()
              NotebookLMClient.from_storage(backend="android")

CLI Exit Code Reference


        

          
            

              Exit Code
              Status
              Meaning & Mitigation
            

          
          
            

              0
              SUCCESS
              Command executed normally and returned clean envelope.
            

            

              1
              GENERAL_ERROR
              Generic unhandled runtime error. Check --verbose for trace.
            

            

              2
              AUTH_EXPIRED
              Cookies expired. Run notebooklm auth refresh or re-login.
            

            

              3
              RATE_LIMITED
              Google throttled requests. Wait 60s or switch to Android backend.
            

            

              4
              NOT_FOUND
              Notebook, source, or artifact UUID does not exist.
